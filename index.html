Privacy Policy / 隐私政策

Extension: Table to Excel & CSV Exporter - Unlimited Local Capture
Effective Date / 生效日期: November 18, 2026

English — Privacy Policy

Table to Excel & CSV Exporter is built on a strict local-first architecture. All table detection, data formatting, CSV/TSV/Markdown/JSON serialization, and Excel (.xlsx) binary file generation happen 100% inside your browser on your local device.

  • Zero Data Collection: We do not collect, store, transmit, sell, or share any personal information, browsing history, webpage contents, or exported table data.
  • Zero External Network Requests: The extension makes no background fetch, XMLHttpRequest, WebSocket, or remote API calls. It works completely offline.
  • Zero Analytics or Cookies: No telemetry, tracking pixels, advertising SDKs, or third-party cookies are included.
  • Minimal Permissions Only:
    • activeTab: Grants temporary access only to the currently active tab when you click the extension icon to scan or highlight tables.
    • scripting: Injects our local table-detection script on demand into the active tab only after user interaction (no persistent background content scripts).
    • storage: Stores your local preferences (number cleaning, link inclusion), Multi-Page Batch table buffer, and optional offline license key strictly inside chrome.storage.local on your device.
  • Zero Broad Host Permissions: We do not request <all_urls> or any persistent host_permissions.

中文 — 隐私政策

Table to Excel & CSV Exporter（网页表格导出 Excel / CSV 工具） 坚持纯本地运行原则。所有网页表格识别、数据清洗、CSV/TSV/Markdown/JSON 转换以及 .xlsx Excel 文件生成均 100% 在您的浏览器本地完成。

  • 零数据收集：本扩展不收集、不存储、不上传、不出售或共享任何个人信息、浏览记录、网页内容或导出的表格数据。
  • 零外部网络请求：扩展内部不包含任何远程 API 请求、fetch、XMLHttpRequest 或后台数据传输，完全支持离线运行。
  • 零统计追踪与 Cookie：不包含任何第三方埋点、遥测、广告 SDK 或追踪 Cookie。
  • 最小化权限说明：
    • activeTab：仅在您主动点击扩展图标时，临时访问当前正在浏览的标签页以读取表格内容。
    • scripting：仅在您点击打开弹窗或刷新时，按需向当前标签页注入本地表格解析脚本（不使用常驻后台 content_scripts）。
    • storage：仅在您设备的 chrome.storage.local 中本地保存导出设置（货币清洗、链接提取）、跨页批量采集缓存（Multi-Page Batch）及离线授权状态，绝不上传至任何服务器。
  • 零全站常驻权限：本扩展不申请 <all_urls> 或任何 host_permissions。

You can inspect all extension source code locally or delete all locally stored batch/setting data at any time by clearing extension storage or removing the extension from Chrome.
